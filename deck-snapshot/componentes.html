Las piezas del intérprete

Compilador

Convierte el árbol en bytecode. Los módulos importados lo guardan en __pycache__.

Máquina virtual

Un bucle escrito en C: lee cada instrucción y ejecuta su código.

Objetos

Cada valor es un objeto de C, con su tipo y un contador de referencias.

Memoria

Libera un objeto cuando su contador llega a cero; un recolector limpia los ciclos.

GIL

En la versión estándar, un solo hilo ejecuta bytecode a la vez.

API de C

La puerta por donde entra el código nativo: NumPy y, con PyO3, Rust.

Contador de referencias: cuántas variables usan un objeto; al llegar a cero, se libera.
GIL (Global Interpreter Lock, bloqueo global del intérprete): deja a un solo hilo ejecutar bytecode a la vez.
API de C (Application Programming Interface): funciones en C para crear y leer objetos de Python. PyO3 la usa desde Rust.

4:45–5:30. Resumen de lo que hay dentro de CPython, sin entrar en el código fuente. Compilador: genera el bytecode; para los módulos que se importan, lo guarda en __pycache__ como archivos .pyc (Python compiled, Python compilado; el script que ejecutas directamente no se guarda así). Máquina virtual: es un bucle en C que lee la siguiente instrucción y salta al código que la implementa; es el trabajo que se repite cientos de millones de veces en la demo. Objetos: incluso un entero es un objeto de C con tipo, valor y contador de referencias; por eso cada operación toca memoria y comprueba tipos. Memoria: cuando el contador llega a cero, el objeto se libera; un recolector aparte limpia los ciclos. GIL, por Global Interpreter Lock (bloqueo global del intérprete): en la compilación estándar de CPython, un solo hilo ejecuta bytecode a la vez; existe una compilación experimental sin GIL, pero no es la que se usa por defecto. API de C, donde API es Application Programming Interface (interfaz de programación de aplicaciones): la pieza clave para esta charla. Es el contrato por el que una biblioteca nativa recibe objetos de Python y devuelve objetos de Python. NumPy la usa desde C; PyO3 la usa desde Rust. Transición: "Y si el trabajo repetido se hace del otro lado de esa puerta, no hace falta cambiar la interfaz".
