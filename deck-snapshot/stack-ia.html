Rust en el stack de IA de Python

HUGGING FACE

tokenizers

Convierte texto en tokens para entrenar y servir modelos.

OPENAI

tiktoken

Cuenta tokens como los modelos de OpenAI: límites y costos.

HUGGING FACE

safetensors

Guarda pesos sin pickle: cargar un modelo no ejecuta código.

PYDANTIC

pydantic-core

Valida las salidas estructuradas de los SDK de LLM.

POLARS

polars

Prepara datos de entrenamiento y de evaluación.

ASTRAL

uv

Instala dependencias y versiones de Python del proyecto.

15:00–16:00.Abrir el foco: Pydantic no es un caso aislado. En el trabajo cotidiano con IA en Python, varias piezas críticas tienen el núcleo en Rust y se usan desde Python. tokenizers (Hugging Face): implementación en Rust con bindings para Python; transformers la usa para los tokenizadores rápidos desde 2020. tiktoken (OpenAI): el bucle de codificación está en Rust y se expone con PyO3. safetensors (Hugging Face): formato para guardar tensores de forma segura, a diferencia de pickle, que puede ejecutar código arbitrario al cargar; además carga rápido. pydantic-core: lo que acabamos de ver. Polars y uv: datos y entornos. Nota de arquitectura: uv es una herramienta (binario), las demás son extensiones que importas. Idea para decir: "Python orquesta; Rust hace el trabajo repetitivo o sensible por debajo". Evitar cifras de velocidad en esta slide: ninguna está medida en la charla.
