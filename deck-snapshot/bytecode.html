for number in range(...):

FOR_ITER
STORE_NAME number

if number % 7 == 0:

LOAD_NAME number
LOAD_CONST 7
BINARY_OP %
LOAD_CONST 0
COMPARE_OP ==
POP_JUMP_FORWARD_IF_FALSE

count += 1

LOAD_NAME count
LOAD_CONST 1
BINARY_OP +=
STORE_NAME count

(fin de la vuelta)

JUMP_BACKWARD

≈ 9 instrucciones por vuelta

× 100 millones de vueltas: cerca de 960 millones de pasos por la máquina virtual.

Bytecode: instrucciones simples que la máquina virtual de Python ejecuta una por una.
Pila: espacio temporal donde las instrucciones dejan y toman valores (LOAD_* los pone, BINARY_OP los usa).
Salida real de python -m dis (disassembler: muestra el bytecode) · Python 3.11; otras versiones cambian nombres

3:45–4:45. Mostrar que el bytecode no es una metáfora: es lo que imprime python -m dis count.py (dis viene de disassembler, desensamblador: muestra el bytecode en texto). Ir de línea a línea: cada línea del bucle se convierte en pocas instrucciones muy simples. LOAD_NAME y LOAD_CONST ponen valores en una pila; BINARY_OP hace el módulo; COMPARE_OP compara con 0; POP_JUMP_FORWARD_IF_FALSE salta si no es múltiplo; JUMP_BACKWARD vuelve al inicio. Contar: son 9 instrucciones por vuelta cuando el número no es múltiplo de 7, y 13 cuando sí lo es (se suman las 4 de count += 1). Cálculo: 100 millones × 9 más 14.285.714 múltiplos × 4 da 957.142.856, es decir cerca de 960 millones de instrucciones. Idea para la audiencia: la máquina virtual repite esa lectura y ejecución casi mil millones de veces; Rust hace el mismo trabajo con unas pocas instrucciones de CPU por vuelta. Matices si preguntan: (1) este script corre a nivel de módulo, por eso aparece LOAD_NAME; dentro de una función sería LOAD_FAST, más rápido. (2) dis muestra las instrucciones base; desde Python 3.11 el intérprete las especializa mientras corre (PEP 659; PEP significa Python Enhancement Proposal, propuesta de mejora de Python), así que no es una medida de tiempo. (3) El conteo sale de dis y de la aritmética, no de una medición. Transición: "¿Y quién ejecuta todo eso? Veamos las piezas del intérprete".
