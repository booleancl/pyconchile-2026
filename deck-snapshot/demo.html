La misma tarea, dos lenguajes

¿Cuántos números entre 1 y N son múltiplos de 7? N llega como argumento.

Python

5,0 s

import sys

limit = int(sys.argv[1])
count = 0

for number in range(1, limit + 1):
    if number % 7 == 0:
        count += 1

print(count)

$ python count.py 100000000

Rust

0,06 s

use std::env;
fn main() {
    let limit: u64 = env::args()
        .nth(1).unwrap()
        .parse().unwrap();
    let mut count = 0;
    for number in 1..=limit {
        if number % 7 == 0 {
            count += 1;
        }
    }
    println!("{count}");
}

$ ./count 100000000

Calentar con un N pequeño que el público pueda comprobar: con 100 la respuesta es 14 (7, 14, …, 98). Luego N = 100 millones: la respuesta es 14.285.714 (100 millones dividido por 7). El código es casi idéntico en los dos lenguajes: leer el límite, un contador, un bucle y "si es divisible por 7, suma uno". En Rust, las líneas de env::args() solo toman el primer argumento y lo convierten a número. Si alguien pregunta por el + 1 de Python: range no incluye el último número; en Rust, 1..= sí lo incluye. Los dos imprimen el mismo resultado: mismo trabajo. El binario Rust ya está compilado con optimizaciones (rustc -C opt-level=3 count.rs): decirlo explícitamente. Como N llega en ejecución, el compilador no puede precalcular la respuesta.
