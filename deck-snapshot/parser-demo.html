No se llama a ningún modelo: las 100.000 respuestas están en un archivo, generadas con make_responses.py con semilla fija, porque lo que medimos es el procesamiento, no la inferencia. Decirlo explícitamente. El modelo Pydantic es idéntico en las dos versiones; solo cambia la llamada: parse_raw en V1 (que hace json.loads y luego valida en Python) y model_validate_json en V2 (que parsea y valida dentro de pydantic-core). Solo se cronometra la validación, no la lectura del archivo. Preparación: generar responses.jsonl antes de la charla (python make_responses.py 100000 > responses.jsonl, unos 44 MB). Para V1, usar un entorno con pip install "pydantic<2"; el script imprime la versión y si está compilada. Si solo hay Pydantic 2, el script usa pydantic.v1 (el código de V1 incluido en V2), que corre como Python puro.
